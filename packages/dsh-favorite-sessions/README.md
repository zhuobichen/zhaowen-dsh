# 常用会话标记（dsh-favorite-sessions）

给不常用、但又不想归档的会话加一个「常用」标记，一键收起其它会话。

## 功能

1. **会话省略号菜单**新增「标记为常用 / 取消常用标记」。
2. **常用会话行首**显示 ⭐。
3. **侧栏 More 菜单**（面板列表那个 ⋯）新增「只显示常用会话」开关：开启后隐藏所有未标记为常用的会话行；关闭即全部显示。

## 为什么这样做

DSH 的「筛选会话」菜单（隐藏已归档 / 全部对话 / 仅显示已归档）是宿主硬编码的，插件无法往里加菜单项。所以「只显示常用」做成了 More 菜单里的开关，效果等同，不动宿主源码。

标记和开关只存在浏览器 localStorage（`dsh.favorite-sessions.v1`），刷新页面、重启 DSH 都在；属个人 UI 偏好，不进会话日志、不进版本库、换浏览器需重新标记。

## 用法

- 在想常留的会话上点 ⋯ → 「标记为常用」。
- 想清净时，侧栏面板列表的 ⋯ → 「只显示常用会话」。
- 再点一次那个开关即恢复显示全部。归档功能完全不受影响——常用标记是独立的。

## 实现

纯客户端插件（宿主半身空）。通过三个官方 slot 扩展：

- `sidebar.workspaces.session.menu.item`（省略号菜单项）
- `sidebar.session.row.leading`（行首星标 + 给行容器打 `data-fav-session`）
- `sidebar.panellist.actions`（More 菜单开关）

开关开启时注入 CSS，隐藏 `[data-row-key^="session:"]:not([data-fav-session])`。
