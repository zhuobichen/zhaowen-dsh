# dsh-novel-pane

在当前会话里开一间**可折叠的读书窗格**。`/novel <文件>` 打开，`/novel` 再敲一次收起。

```
┌ 试验小说.txt ─────────────────────────────┐
│ [⇄ 卷轴] [↑] [↓] [⌂] [☰]   7/20700        │  ← 表头：按钮 + 进度
│ 第一章　夜航                               │
│ 船在雾里走，灯是唯一的方向。               │
└───────────────────────────────────────────┘
```

移植自 Claude Code 的 `novel-pane` mod；画窗格的是
[`@zhuobichen/dsh-client-ui-novel-pane`](../dsh-client-ui-novel-pane)。

## 和 Claude Code 版的差别

| | Claude Code 版 | 这一版 |
| --- | --- | --- |
| 窗格位置 | 提示框上方、引擎给的窗格 | 输入框上方（`conversation.input.dock`，order 16） |
| 折行 | 按终端格子折（汉字两格） | **按源文件的行分页**，浏览器自己折行 |
| 翻页 | `e.by` 自己移行 | 位置是**顶行序号**，写盘、跨会话保留 |
| 控件顶栏 | 窗格第一行，靠「只画一屏」避免滚走 | 普通 flex 表头，天然不滚 |
| 键盘 | j/k/空格/gg/G | 按钮 + 滚轮（Web 里没有可靠的焦点抢夺） |

## 命令

| 打什么 | 做什么 |
| --- | --- |
| `/novel <文件>` | 打开一本（相对路径按会话工作目录算） |
| `/novel n` | 下一页，并把这一页打在对话里 |
| `/novel p` | 上一页 |
| `/novel 12` | 跳到第 12 页 |
| `/novel read` | 把当前页打出来，不动位置 |
| `/novel shelf` / `list` | 列出当前目录里能读的文件（`.txt/.md/.markdown/.text/.log`） |
| `/novel` | 窗格开着就收起；没开就把上次那本打开 |

## 窗格

- **⇄** 切换模式：卷轴（滚轮一次一行）／整屏（滚轮一次一屏）
- **↑ / ↓** 按当前模式移动；**⌂** 回到开头；**✕** 收起
- **☰** 切书单：点书名换书
- 位置写在 `$DSH_HOME/plugins/dsh-novel-pane/state.json`，下次接着读
